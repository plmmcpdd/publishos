# PublishOS — Product Requirements Document

## 1. 产品定位

PublishOS 是美国社交媒体代运营服务商的后端交付系统，支持中国团队为美国本地 SMB（HVAC、plumbing、AI 初创）提供 TikTok 等内容平台的合规代运营服务。

核心目标：让内容生产在中国完成，发布行为在美国本地执行，全程合规可审计。

## 2. 用户角色

### 2.1 蓝领客户（Client Owner）
- 典型画像：HVAC/plumbing 小老板，40-55 岁，非技术背景
- 核心诉求：不费力地持续发布社交媒体内容，吸引本地客户
- 使用场景：每天看到系统托盘通知，点一下确认发布，或直接信任团队自动发布
- 使用频率：每天 1-2 次（确认发布），每周看一次发布数据

### 2.2 美国运营审核员（US Operator）
- 负责内容合规预审：检查 AI 披露标签、素材授权、广告用语合规
- 使用运营后台 Dashboard：批准/驳回内容，监控客户账号健康度
- 地理要求：必须在美国本土，或至少在美国时区工作

### 2.3 中国内容交付团队（Content Team）
- 使用平台（扣子/Coz）生成脚本和视频
- 使用正版素材库（Envato/Artgrid）获取素材
- 将成品上传至 PublishOS 网关，等待美国运营审核
- 不参与客户账号操作，不接触账号凭证

## 3. 核心流程

```
[中国内容团队] → 上传内容至网关 → [美国运营审核] → 批准/驳回 → 
→ 进入客户端队列 → [蓝领客户 App 确认] → 本地浏览器自动发布 → 
→ 状态回传网关 → [后台 Dashboard 监控]
```

### 3.1 内容创建流程（中国团队）
1. 在扣子平台完成 AI 内容生成
2. 导出视频 + 文案，确认素材授权来源（Envato ID / 客户自有素材）
3. 在 PublishOS 后台上传内容，标注：
   - 目标客户（client_id）
   - 目标平台（tiktok）
   - AI 生成标记（ai_generated: true）
   - 素材授权链条（license_chain）
   - 计划发布时间（scheduled_at）
4. 内容状态：pending_review

### 3.2 审核流程（美国运营）
1. 运营后台 Dashboard 显示「待审核」内容列表
2. 运营检查：
   - AI 披露标签是否正确
   - 素材授权是否完整（License Missing 时 Approve 按钮禁用）
   - 文案是否包含合规风险（蓝领行业广告用语预审）
   - 发布计划时间是否合理
3. 点击「Approve」→ 状态变为 approved，进入客户端队列
4. 点击「Reject」→ 填写驳回原因，内容退回中国团队修改

### 3.3 客户端发布流程（蓝领客户）
1. 内容进入客户端 App「待发布」队列
2. 系统托盘弹出通知（Windows/Mac）："有一条新内容等待确认发布"
3. 客户打开 App，看到内容卡片（缩略图 + 标题 + 发布时间 + AI 标签）
4. 客户点击「确认发布」→ 二次确认弹窗：
   - 标题："Publish to TikTok?"
   - 内容："This will post '[title]' to your TikTok with AI-generated disclosure."
   - 按钮：「Cancel」「Open Browser」
5. 点击「Open Browser」→ 本地浏览器自动打开 TikTok 上传页面，预填文案和标签
6. 客户看到熟悉的 TikTok 界面，点击 TikTok 的「发布」按钮完成最终确认
7. 发布状态回传网关，客户端显示「Done」

### 3.4 自动发布（信任后）
- 客户可在「设置」开启 Auto-Publish
- 开启后，经过审核的内容不再弹通知确认，客户端自动打开浏览器执行发布
- 客户仍可关闭 Auto-Publish，随时恢复手动确认
- 建议：v1 上线时 Auto-Publish 开关放在 Tab 1 顶部（全局操作），v2 再优化

## 4. 功能模块

### 4.1 客户端 App（Electron 桌面端）

**三屏结构：**

| Tab | 名称 | 核心功能 |
|-----|------|---------|
| Tab 1 | Queue（待发布） | 待发布内容卡片列表、确认发布按钮、Auto-Publish 全局开关 |
| Tab 2 | History（历史） | 发布历史列表、成功/失败状态、查看数据 |
| Tab 3 | Settings（设置） | 账号绑定状态、通知偏好、AI 披露标签开关、自动发布开关 |

**托盘功能：**
- 常驻系统托盘（Windows/Mac）
- 新内容到达时弹出通知
- 右键菜单：Open Queue / History / Settings / Quit
- 点击通知直接打开 App 到 Queue 页

**通知策略：**
- 新内容到达：桌面通知 + 托盘图标闪烁（黄色）
- 发布成功：静默更新，History 页显示绿色 Done
- 发布失败：桌面通知 + 托盘图标变红 + 卡片显示重试按钮
- 账号健康异常（shadowban suspected）：紧急通知 + 弹窗提醒

### 4.2 运营后台 Dashboard（Web）

**三栏布局：**

| 左栏 | 中栏 | 右栏 |
|------|------|------|
| 客户列表（带健康度条） | 内容审核流（Pending/Approved/Rejected） | 实时指标 + 账号健康评分 |

**左栏 — 客户列表：**
- 客户名称 + 行业标签 + 当前平台
- 健康度条（绿/黄/红）：综合指标 = 发布成功率 + 账号活跃状态 + 风控评分
- 筛选：按状态、行业、平台

**中栏 — 内容审核流：**
- 卡片列表：缩略图 + 标题 + 客户 + 计划时间 + 平台 + AI 标签
- 操作按钮：Approve（授权完整时可用）/ Reject（弹出原因输入）
- License Missing 时 Approve 按钮禁用，显示「快速修复」入口
- 审核后卡片状态即时更新（不用刷新页面）

**右栏 — 实时监控：**
- 今日发布成功率（百分比）
- 待审核数量
- 待确认发布数量（客户端队列）
- 账号健康异常列表（shadowban / 风控警告）
- 素材授权到期提醒

### 4.3 发布网关（Backend）

核心接口（详见 `API-CONTRACT-v1.0.md`）：
- 内容创建（中国团队）
- 内容审核（美国运营）
- 任务队列（客户端拉取）
- 状态回传（客户端上报）
- 审计查询（Dashboard 数据）
- 账号健康监控（轮询各平台）

## 5. 平台优先级

| 优先级 | 平台 | 发布方式 | 原因 |
|--------|------|---------|------|
| P0 | TikTok | 客户端本地浏览器（TikTok web） | 客户主力平台，团队最熟悉 |
| P1 | Instagram | SaaS API（Meta Graph API）或客户端本地 | 客户集中度次高，Graph API 成熟 |
| P2 | Facebook | 同 Instagram | 同平台体系，复用 Graph API |
| P2 | X / Twitter | X API v2 | 文字内容为主，API 成熟 |
| P3 | YouTube Shorts | 客户端本地浏览器（YouTube web） | 视频平台，但客户浓度较低 |

v1 只接 TikTok。P1 平台在 v2 接入。

## 6. 安全与权限

| 角色 | 能访问的内容 | 不能访问的内容 |
|------|-------------|---------------|
| 中国内容团队 | 自己的内容库、素材库、客户基本信息 | 客户账号密码、API Token、审计日志 |
| 美国运营审核 | 所有待审内容、客户列表、审核历史 | 中国团队的素材生成工作流（扣子） |
| 蓝领客户 | 自己的内容、发布历史、账号状态 | 其他客户数据、后台审核流、素材来源 |
| 系统管理员 | 全部 | 明文密码（加密存储） |

**零信任原则：**
- 所有 API 调用需认证（Bearer Token）
- 客户端设备 token 与硬件绑定
- 任务 token 一次性使用，只能回传单条任务状态
- 账号凭证（密码/Token）不存服务器，由客户端本地浏览器管理
- 中国团队访问美国 VPC 需通过 Tailscale 零信任 VPN + Bastion 跳板

## 7. 数据与隐私

- 客户个人信息（PII）仅存储在美国 AWS VPC，不出境
- 中国团队的工作产物（视频工程文件、脚本）在加密传输到美国后，本地副本 7 天内清除
- 审计日志保留 3 年，包含：操作人员、时间、IP、设备指纹、操作结果
- 符合 CCPA 和 GDPR（若有欧洲客户）的数据处理要求

## 8. 非功能需求

| 指标 | 目标 | 说明 |
|------|------|------|
| 客户端启动时间 | < 3 秒 | 从点击图标到可交互 |
| 队列拉取延迟 | < 5 秒 | 从审核通过到客户端显示 |
| 发布状态回传延迟 | < 10 秒 | 从客户端点击到后台更新状态 |
| 通知送达率 | > 99% | 桌面通知在系统层面可靠送达 |
| 系统可用性 | 99.5% | 发布网关，不含平台方故障 |
| 同时在线客户 | 100 | v1 支持并发，后续可扩展 |
| 单客户内容库容量 | 10GB | 视频素材，可扩展 |

## 9. 验收标准

### v1 上线标准
- [ ] 客户端 App 能正常安装、登录、显示待发布队列
- [ ] 中国团队能上传内容，美国运营能审核批准/驳回
- [ ] 审核通过的内容能进入客户端队列，客户端能确认发布
- [ ] 发布状态（成功/失败）能回传后台，Dashboard 正确显示
- [ ] TikTok 网页版发布自动化验证通过（spike 标准：能稳定跑 30 天不触发风控）
- [ ] AI 披露标签在 TikTok 发布时自动勾选
- [ ] 审计日志完整记录所有操作
- [ ] 所有 API 接口有认证保护，无未授权访问漏洞
- [ ] 客户端支持 Windows 10+ 和 macOS 12+（Apple Silicon + Intel）
