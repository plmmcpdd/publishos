# PublishOS — 合规 SOP 手册

## 1. AI 内容披露规则

### 1.1 法定要求（FTC）

AI 生成的广告/推广内容必须向消费者披露。披露必须：
- **清晰且显著**：不能放在脚注或需要点击展开的地方
- **难以忽视**：在内容本身中，而非仅靠标签
- **在内容出现的地方**：同一内容出现在多个平台，每个平台都需披露

**披露用语标准（v1）：**
| 场景 | 用语 |
|------|------|
| 视频开头或结尾 | "This video was created with AI" |
| 文案中 | "#AIgenerated" 或 "Created with AI" |
| 付费广告 | 文案开头必须加 "#ad" 或 "#sponsored" + AI 披露 |

### 1.2 平台强制标签（自动化要求）

| 平台 | 标签要求 | 实现方式 | 自动化方案 |
|------|---------|---------|------------|
| **TikTok** | AI-generated 内容必须勾选平台标签；photorealistic 人像强制标签 | 上传时勾选 "AI-generated" | 发布网关自动设置 `ai_label: "ai-generated"` |
| **Instagram** | photorealistic AI 内容标记 "Made with AI" | Meta 自动检测或人工标记 | Graph API 设置 `is_ai_generated: true` |
| **Facebook** | 同 Instagram | 同上 | 同上 |
| **YouTube** | altered/synthetic 内容标记 | 上传流程勾选 | 客户端本地浏览器手动勾选（暂不能自动） |
| **X/Twitter** | 目前无强制标签，但付费广告需 FTC 披露 | 文案中加 #AIgenerated | 网关自动在文案前添加披露语 |

**阻断规则：** 任何 `ai_generated: true` 的内容，如果缺少目标平台的披露标记，发布网关自动阻断，状态变为 `blocked_compliance`。

## 2. 素材授权合规

### 2.1 素材来源白名单

| 来源 | 类型 | 授权要求 | 使用方式 |
|------|------|---------|----------|
| **Envato Elements** | 视频/音乐/字体 | Business 订阅，商用覆盖 | 记录订阅发票和授权协议，保留 ID |
| **Artgrid** | 视频素材 | Universal 订阅 | 同上 |
| **客户自有素材** | 照片/视频/Logo | 客户签署「素材使用授权书」 | 授权书 PDF 存入系统，关联 content |
| **AI 纯生成** | 图片/视频 | 确认服务商商业许可（Midjourney Business / Runway） | 记录服务商和订阅级别 |
| **平台 API 元数据** | 趋势数据（标题/标签/播放量） | 通过官方 Research API 获取 | 仅用于策略分析，不直接下载视频 |

### 2.2 禁止行为（黑名单）

- ❌ 爬取、下载、录屏任何社交媒体上的热门视频作为"对标素材"
- ❌ 使用 AI 工具对热门视频进行"拆解"、"改写"、"模仿"
- ❌ 使用免费素材网站（Pexels / Pixabay）声称"免费商用"（多数平台免费授权不含社交媒体代运营转授权）
- ❌ 使用 AI 生成的内容冒充真人（deepfake、语音合成冒充客户本人）
- ❌ 使用未授权音乐（包括 TikTok 热门 BGM 的商业使用）

### 2.3 授权记录规范

每条内容必须关联 `license_chain`：
```json
[
  {
    "source": "envato",
    "id": "video_12345",
    "license_type": "elements_business",
    "subscription_id": "sub_abc",
    "expires_at": "2026-12-31"
  }
]
```

**License Missing 阻断：** 内容创建时如果未填写 `license_chain` 或授权已过期，系统标记 `license_status: missing`，美国运营审核时 Approve 按钮禁用，显示「快速修复」入口。

## 3. 蓝领行业广告合规

### 3.1 州级 Contractor 执照要求

以下州要求在社交媒体广告中披露 contractor 执照号：
- **California**（CSLB 执照号）
- **Texas**（TDLR 注册号）
- **Florida**（County-level 执照号）
- **New York**（Department of Consumer Affairs 执照）
- **Nevada**（NSCB 执照号）

**操作要求：** 客户签约时，美国运营必须核验其州级执照号，并在广告文案中标注（如 "Licensed Contractor #CSLB-123456"）。

### 3.2 禁止广告用语（高风险）

| 用语 | 风险 | 州级 |
|------|------|------|
| "最低价保证" / "Best Price Guarantee" | 违反消费者保护法（虚假承诺） | 加州、德州、纽约 |
| "免费检查" / "Free Inspection"（无附加条件） | 可能被视为诱导性广告 | 部分州要求明确附加条件 |
| "立即节省 $500" | 未经证实的折扣声明 | FTC 虚假广告 |
| "Licensed & Bonded"（无具体执照号） | 模糊广告，州级执法 | 多州 |
| 客户 before/after 照片（未经书面授权） | 隐私侵权 | 全美 |

**审核规则：** 运营后台对以上内容自动检测关键词，命中时标记 `high_risk_ad_copy`，审核员必须确认并修改后才能通过。

### 3.3 客户预审 Checklist

新客户签约时，美国运营必须完成：
- [ ] 核验州级 contractor 执照号（官网查询）
- [ ] 确认执照在有效期内
- [ ] 确认客户同意在广告中披露执照号
- [ ] 检查广告文案是否包含禁用用语
- [ ] 客户签署「广告合规确认书」
- [ ] 客户签署「素材使用授权书」
- [ ] 客户确认 AI 内容披露方式和标签

## 4. 平台运营合规

### 4.1 账号安全规则

| 规则 | 要求 | 违规后果 |
|------|------|---------|
| 一号一环境 | 每个客户账号在独立的网络/设备环境中运行 | 多账号共享 IP = 平台封号 |
| 登录态管理 | 客户自己登录，代运营方不持有密码 | 密码泄露 = 客户追责 + 平台违规 |
| 发布频率 | 自然流每天 1-2 条，不突击批量发布 | 批量发布 = 平台判定 spam |
| 内容原创比例 | 原创/AI 生成内容 ≥ 80%，引用/改写 ≤ 20% | 搬运内容过多 = 版权投诉 |
| 互动真实性 | 不购买粉丝/点赞/评论 | 虚假互动 = 平台永久封号 |

### 4.2 账号健康监控

**每日检查项：**
- shadowban 检测：搜索客户最新帖子的 hashtag，确认是否出现在搜索结果中
- 粉丝增长异常：单日粉丝增减 > 20% 时告警（可能 bought followers 或 shadowban）
- 发布失败率：连续 3 条发布失败时告警
- 账号被封/限制：登录状态检测，账号不可用时立即通知客户和运营团队

**shadowban 检测方法（无官方 API）：**
1. 从非登录状态访问客户 profile URL
2. 检查最新帖子是否可见
3. 检查帖子的 hashtag 页面是否包含该帖子
4. 如果不可见，标记为 shadowban suspected，通知客户和运营

## 5. 中美公司架构合规

### 5.1 责任隔离原则

- **美国公司（USCo）**：签约客户、持有客户数据、运营审核、发布权限、法律主体
- **中国公司（ChinaCo）**：内容生产、素材制作、创意执行
- **两家公司关系**：服务采购协议（MSA），ChinaCo 向 USCo 提供内容制作服务，USCo 保留 margin

### 5.2 美国公司"实体性"要求

为避免被法院认定为"壳公司"，USCo 必须证明：
- 有美国本地员工（至少 part-time）
- 有美国办公地址（virtual office 可）
- 有美国银行对公账户和报税记录
- 有美国电话和邮箱（客户可联系）
- 有实际运营记录（会议记录、运营日志、合同归档）

### 5.3 保险要求

- **Errors & Omissions Insurance（职业责任险）**：覆盖因代运营服务导致的客户损失
- **Cyber Liability Insurance**：覆盖数据泄露、系统被入侵等网络安全事件
- 年保费：$2k-$5k，保额可达 $1M

## 6. 数据合规

### 6.1 数据不出境

- 客户个人信息、账号数据、发布记录仅存储在美国 AWS VPC
- 中国团队的工作产物（视频、脚本）在加密传输到美国后，中国本地副本 7 天内清除
- 中国团队通过 Tailscale 零信任 VPN 访问美国 VPC，禁止直接访问平台 API

### 6.2 审计日志

保留期：3 年
每条记录包含：
- 操作时间（UTC + 客户时区）
- 操作人员 ID
- 操作类型（创建/审核/发布/修改/删除）
- 操作对象（content_id / task_id）
- 操作结果（成功/失败）
- 设备指纹（客户端 IP、设备 ID）
- AI 披露标签状态
- 素材授权编号

## 7. 合规事件处理流程

```
[发现合规事件] → 立即暂停相关内容的发布 → 通知美国运营负责人 → 
→ 评估事件等级（Low/Medium/High/Critical） → 
→ Low: 运营自行修复 → Medium: 通知客户，协商修复 → 
→ High: 暂停该客户所有内容，启动内部审查 → 
→ Critical: 立即通知法务/保险，启动应急响应 → 
→ 记录事件日志，更新 SOP 防止复发
```

**事件等级定义：**
| 等级 | 场景 | 响应时间 |
|------|------|---------|
| Low | 单个内容的 AI 标签遗漏 | 24h 内修复 |
| Medium | 单个内容的素材授权缺失 | 4h 内通知客户，24h 内修复 |
| High | 客户账号被封 / 平台投诉 | 1h 内响应，暂停所有相关内容 |
| Critical | 版权诉讼 / FTC 调查 / 数据泄露 | 30min 内响应，通知法务 |

## 8. 合规培训

- 新运营入职：必须完成合规 SOP 培训并通过测试（通过率 100%）
- 中国团队：每月一次合规例会，回顾案例和更新规则
- 美国运营：每季度一次合规 audit，由第三方或 USCo 负责人执行
- 客户：签约时提供「合规须知」PDF，包含 AI 披露、广告用语、账号安全规则
